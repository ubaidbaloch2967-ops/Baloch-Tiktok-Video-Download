How to publish on GitHub Pages:

2. Create a NEW GitHub repository for this website (recommended), or use a separate repository from your drama website.
3. Upload index.html and ubaid.jpg to the repository root.
4. In Settings > Pages, enable deployment from the main branch and root folder if needed.
